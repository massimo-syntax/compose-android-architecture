# Instruction - Skill files:

> **`INSTRUCTION_*.md`** files are precision-curated prototypes used to implement specific parts of micro-projects or demo applications. Every instruction across all files is first written by hand, formatted by AI, and then reviewed for practical use.

---

## 🎯 Architectural Philosophy

### 1. Instruction Prototypes (`INSTRUCTION_*.md`)
* **Handwritten & Refined:** Each specification originates from manual implementation notes, piece by piece, formatted and reviewed before practical application.
* **Micro-Project Focus:** Serves as targeted, deterministic blueprints for modern Android architecture patterns.

### 2. Executable Skills (`SKILL_*`)
* **Finished Products:** The `SKILL_*` files represent the final, battle-tested standard that AI agents execute with clean, modern code and reliable results.
* **Model Optimization:** Specifically optimized to work seamlessly with cost-effective and free AI models, enabling them to apply instructions without struggling or adding unnecessary code, libraries, etc.
